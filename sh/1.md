# 节点信息 HTTPS 加密分享配置指南

本指南基于现有的 Nginx 与 Let's Encrypt 正式证书（`/etc/pxy/cert.pem`），通过**独立高位随机端口 + 随机 UUID 路径**的方式，安全地将 `/etc/pxy/nodes.txt` 转换为可通过 HTTPS 访问的在线节点订阅链接。

---

## 一、 生成随机端口、UUID 并提取有效节点

由于 `/etc/pxy` 目录权限受限（仅 `root` 与 `pxy` 用户组可访问），Nginx 默认运行用户无法直接读取。需在 `/var/www/pxy-sub` 下创建独立文件存放过滤后的节点链接：

```bash
# 1. 生成随机高位端口 (20000-60000) 与随机 UUID
SUB_PORT=$(shuf -i 20000-60000 -n 1)
SUB_UUID=$(cat /proc/sys/kernel/random/uuid)

# 2. 创建独立存放目录并过滤注释行与空行
mkdir -p /var/www/pxy-sub
grep -v '^#' /etc/pxy/nodes.txt | grep -v '^$' > "/var/www/pxy-sub/$SUB_UUID"

# 3. 设置目录与文件权限
chmod 755 /var/www/pxy-sub
chmod 644 "/var/www/pxy-sub/$SUB_UUID"
```

> **提示**：若希望生成通用 Base64 编码订阅格式（兼容各类客户端直接填入订阅 URL），可将上述提取命令替换为：
> ```bash
> grep -v '^#' /etc/pxy/nodes.txt | grep -v '^$' | base64 -w0 > "/var/www/pxy-sub/$SUB_UUID"
> ```

---

## 二、 配置独立 HTTPS 订阅端口 (Nginx)

创建 `/etc/nginx/conf.d/pxy-sub.conf`，复用现有域名与证书，并对非精确匹配 UUID 的探测请求直接断开连接（返回状态码 `444`）：

```bash
cat > /etc/nginx/conf.d/pxy-sub.conf <<EOF
server {
    listen $SUB_PORT ssl http2;
    listen [::]:$SUB_PORT ssl http2;
    server_name api.touzi.dpdns.org;

    ssl_certificate     /etc/pxy/cert.pem;
    ssl_certificate_key /etc/pxy/cert.key;
    ssl_protocols       TLSv1.3 TLSv1.2;
    server_tokens       off;

    root /var/www/pxy-sub;
    autoindex off;

    # 仅允许精确匹配该 UUID 路径
    location = /$SUB_UUID {
        default_type text/plain;
        charset utf-8;
        try_files \$uri =404;
    }

    # 其他任何路径探测直接丢弃连接
    location / {
        return 444;
    }
}
EOF

# 校验并重载 Nginx 配置
nginx -t && systemctl reload nginx
```

---

## 三、 放行防火墙并获取分享链接

若系统开启了 `ufw`，需放行该随机端口；**同时请务必前往云厂商控制台的「安全组/防火墙」面板放行该 TCP 端口**。

```bash
# 1. 放行本地 UFW 防火墙
if command -v ufw >/dev/null && ufw status | grep -q "Status: active"; then
  ufw allow "$SUB_PORT/tcp" >/dev/null
fi

# 2. 打印最终分享链接
echo "你的加密分享链接为："
echo "https://api.touzi.dpdns.org:$SUB_PORT/$SUB_UUID"
```

---

## 四、 后续维护与更新

* **更新节点内容**：当 `/etc/pxy/nodes.txt` 发生变更后，执行以下命令即可同步刷新在线订阅内容（替换 `<你的UUID>` 为实际文件名）：
  ```bash
  grep -v '^#' /etc/pxy/nodes.txt | grep -v '^$' > "/var/www/pxy-sub/<你的UUID>"
  ```
* **证书自动续签**：脚本原有的 `/usr/local/sbin/pxy-cert-deploy` 钩子已包含 `systemctl reload nginx`，后续 `certbot` 自动续签证书时，该分享端口会自动加载新证书，无需人工干预。
* **撤销分享**：如需关闭分享链接，删除 `/etc/nginx/conf.d/pxy-sub.conf` 及 `/var/www/pxy-sub` 目录，并执行 `systemctl reload nginx` 即可。
